# 导航与应用框架

## 应用框架

登录后页面统一由 `AppLayout.vue` 提供：

- 左侧导航抽屉。
- 顶部页面标题与全局工具区。
- 最大宽度主内容区。
- 主题切换、用户信息、退出、任务提示和版本更新提示。

功能页不得重复实现这些全局元素。

## 侧边导航

- 桌面宽度 `280px`。
- 抽屉内容距视口 `16px`，紧凑布局为 `12px`。
- 表面使用 `--lp-surface`、`--lp-border` 和轻阴影。
- 品牌区固定高度 `72px`。
- 导航列表独立纵向滚动，品牌区不随列表滚动。

## 导航分组

- 单入口组直接渲染 `v-list-item`。
- 多入口组使用 `v-list-group`。
- 一级分组应有图标；二级入口在需要视觉区分时可配置图标。
- 标题来自 i18n，不在导航配置中写固定用户可见文案。
- 路由当前项由 Vuetify active 状态表达。

## 导航项状态

- 默认：弱文本色。
- 悬浮：主文本色和极弱表面背景。
- 激活：主色文字、淡主色背景、左侧 `3px` 主色指示条。
- 圆角 `8px`，上下间距 `2px`。
- 禁用状态使用 Vuetify 原生 disabled，不自行降低透明度模拟。

## 页头

- 使用 `.app-header.panel`。
- 最小高度 `64px`，桌面横向两端分布。
- 标题来自路由 `meta.titleKey`。
- 右侧全局操作允许换行。
- `980px` 以下页头改为纵向布局。
- `640px` 以下用户区和退出按钮进一步占满可用宽度。

## 移动端

- `mdAndDown` 使用 temporary drawer。
- 页头显示菜单图标按钮。
- 路由切换后自动关闭抽屉。
- 菜单按钮必须有本地化 `aria-label`。

## 品牌标识

- 当前标识为 `LP` 字母块。
- `38px` 方形、`8px` 圆角、主色渐变。
- 品牌名称和副标题来自 i18n。
- 登录页可使用放大版本，但保持相同主色和字母标识语言。

## 全局提示

- 活跃任务以紧凑 ticker 展示，文本单行省略。
- 新版本只用 warning tonal Chip 弱提示，不在页头提供安装动作。
- 全局工具区不放页面特有按钮。

## 禁忌

- 不在 feature 页面新增第二套侧边栏或顶栏。
- 不让导航列表溢出视口而无法滚动。
- 不在路由元信息中写已翻译标题。
- 不把页面筛选器放进全局页头。

## 源码依据

- `web/src/layouts/AppLayout.vue`
- `web/src/router/index.ts`
- `web/src/styles/main.css`
