# 导航与应用框架

## 应用框架

登录后页面统一由 `AppLayout.vue` 提供：

- 左侧导航抽屉。
- 顶部页面标题与全局工具区。
- 最大宽度主内容区。
- 主题设置、账户菜单、任务提示和版本更新提示。

功能页不得重复实现这些全局元素。

## 侧边导航

- 桌面宽度 `280px`。
- 抽屉内容距视口 `16px`，紧凑布局为 `12px`。
- 表面使用 `--lp-surface`、`--lp-border` 和轻阴影。
- 品牌区固定高度 `72px`。
- 导航列表独立纵向滚动，品牌区不随列表滚动。

## 导航分组

- 单入口组直接渲染 `v-list-item`。
- 多入口组使用 `v-list-group`。
- 一级分组应有图标；二级入口在需要视觉区分时可配置图标。
- 标题来自 i18n，不在导航配置中写固定用户可见文案。
- 路由当前项由 Vuetify active 状态表达。
- “服务器”一级分组只包含节点和凭据等基础服务器管理入口。
- “安全”一级分组排列在“服务器”之后，包含防火墙和 fail2ban；防火墙只管理 UFW，fail2ban 使用独立页面。
- “资源”一级分组包含软件包、容器、镜像、网络和卷。
- “应用”一级分组包含应用和设施应用。
- 旧 `/servers/firewall`、`/servers/packages` 与 `/containerization/*` 地址只作重定向，不保留重复导航入口。
- “证书”一级分组包含域名证书、自签证书和密钥；旧“密钥与证书”地址只重定向到自签证书，不保留重复导航入口。

## 导航项状态

- 默认：弱文本色。
- 悬浮：主文本色和极弱表面背景。
- 激活：主色文字、淡主色背景、左侧 `3px` 主色指示条。
- 圆角 `8px`，上下间距 `2px`。
- 禁用状态使用 Vuetify 原生 disabled，不自行降低透明度模拟。

## 页头

- 使用 `.app-header.panel`。
- 最小高度 `64px`，桌面横向两端分布。
- 标题来自路由 `meta.titleKey`。
- 桌面端标题、活跃任务 ticker 和全局操作横向排列。
- `980px` 以下页头使用紧凑单行：菜单、标题和工具按钮保持同排。
- 活跃任务存在时，ticker 独占页头第二行；没有任务时不保留空白行。
- 页头所有宽度下都不直接展示用户名和退出按钮；只展示可访问的账户图标按钮，点击后在菜单中显示用户名和退出入口。
- 版本提示在窄屏压缩显示，不得迫使工具按钮换成多行。
- 系统版本 API 返回 `dev` 构建通道时，在标题旁显示 info tonal 的紧凑 `DEV` Chip；完整构建版本放在本地化 tooltip 中。正式通道不显示该标识。
- 原浅色/深色切换按钮使用主题图标入口替代；菜单内提供自动、浅色、深色模式，以及明暗共用或分别选择主题预设。

## 移动端

- `mdAndDown` 使用 temporary drawer。
- 页头显示菜单图标按钮。
- 路由切换后自动关闭抽屉。
- 菜单按钮必须有本地化 `aria-label`。

## 品牌标识

- 当前标识为 `LP` 字母块。
- `38px` 方形、`8px` 圆角、主色渐变。
- 品牌名称和副标题来自 i18n。
- 登录页可使用放大版本，但保持相同主色和字母标识语言。

## 全局提示

- 活跃任务以紧凑 ticker 展示，文本单行省略。
- 窄屏中活跃任务 ticker 是页头唯一允许新增的行。
- 新版本只用 warning tonal Chip 弱提示，不在页头提供安装动作。
- 全局工具区不放页面特有按钮。
- 主题菜单修改后即时预览并保存到当前浏览器，不提供额外保存按钮。
- 账户菜单将用户名作为非操作信息展示，将退出登录作为带图标的菜单项展示。

## 禁忌

- 不在 feature 页面新增第二套侧边栏或顶栏。
- 不让导航列表溢出视口而无法滚动。
- 不在路由元信息中写已翻译标题。
- 不把页面筛选器放进全局页头。
